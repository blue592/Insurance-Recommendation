# 보험추천 — 기획서

> 문서 상태: 기획 확정 / 구현 전  
> 작성일: 2026-11-11  
> 목표 산출물: 서버·로그인·외부 연결 없이 실행되는 단일 HTML

## 1. 대상 사용자

- 본인과 친구 등 소수의 개인 사용자
- 보험상품을 관심 단어로 간편하게 탐색하고 비교하려는 사람
- PC, 아이폰, 안드로이드 사용자

## 2. 사용 목적

사용자가 관심 있는 단어 하나 또는 여러 개를 입력하면, 미리 검증하여 HTML에 포함한 국내 보험상품 중 관련성이 높은 상품을 **최대 5개** 보여준다. 추천상품의 주요 보장과 가입조건을 확인하고 비교할 수 있도록 한다. 이는 개인의 실제 가입 승인이나 보험금 지급을 보증하는 서비스가 아니다.

## 3. 화면 구성과 동작

### 3.1 첫 화면

- 중앙에 큰 검색 입력창과 사용 안내를 배치한다.
- 파스텔톤, 둥근 카드·버튼, 간결한 아이콘을 사용한다.
- 최근 검색어는 첫 화면에, 즐겨찾기는 별도 메뉴에 표시한다.

### 3.2 검색어 등록

1. 사용자가 단어를 입력하고 Enter를 눌러 검색어 칩으로 등록한다.
2. 검색어는 최대 5개까지 등록한다. 칩의 `×`로 삭제하고 다시 입력할 수 있다.
3. 쉼표는 자동 제거한다. 중복 단어는 등록하지 않고 안내한다.
4. 빈칸·공백만 입력한 채 검색하면 **“검색어를 입력해 주세요.”**라고 안내한다.
5. `검색하기`를 누를 때 확정된 검색어를 한 번에 처리한다. 검색어를 수정한 뒤 다시 검색하기 전에는 기존 결과를 `이전 검색 결과`라고 표시한다.

### 3.3 검색·추천 결과

- 상품명과 **주요 보장명**을 검색한다. 부가적인 상세 설명만 일치하는 것은 추천 검색 대상에서 제외한다.
- 가입연령·가입대상·가입조건 검색어는 상품 DB의 조건 용어 목록과 나이·성별 기본 규칙으로 구분하고, 추천 점수와 별개의 통과·제외 필터로 사용한다.
- 가입조건이 하나라도 명확히 불일치하면 일반·유사상품 모두에서 제외한다. 가입조건 미확인 상품은 조건 검색어가 없는 경우에만 후순위 추천할 수 있다.
- 일반 관심 보장이 있으면 관련 상품을 우선하여 **최대 5개** 추천하고, 부족하면 조건에 맞는 유사상품을 구분해 표시한다. 같은 보험사는 최대 2개까지만 선정한다.
- 추천 카드에는 순위, 보험사, 상품명, 주요 보장, 한 줄 추천 이유와 `직접 관련`/`유사상품` 배지를 보여준다.
- 가입조건만 검색하면 점수·순위 없이 일치 상품 전체를 보험회사명·상품명 가나다순으로 정렬하고, 처음 5개 이후 `더 보기`로 5개씩 추가 표시한다. 관심 보장을 추가하면 최대 5개 추천으로 전환한다.
- 결과가 5개보다 적으면 찾은 개수만 표시하고 검색어 수정 안내를 보여준다.

### 3.4 비교·상세보기·출력

- 추천 카드 아래 자동 비교표에 보험회사·상품명·보험 종류·주요 보장을 표시한다.
- 모바일에서는 비교표를 상품별 세로 카드로 전환한다.
- 상세 팝업에 주요 보장·특약·가입조건을 표시한다. 가입 가능한 연령의 정확한 범위도 상세 팝업에서 확인한다.
- 상품별 공식 자료 검증일 및 당시 판매 확인 상태를 화면에 표시한다.
- 브라우저 인쇄 기능으로 추천 카드와 비교표를 PDF로 저장할 수 있게 한다.
- 검색기록과 즐겨찾기는 열린 HTML 실행 중에만 유지하고, 파일을 새로 열면 초기화한다. 사용 중 기록 초기화 버튼도 제공한다.

## 4. 추천 규칙

| 평가 요소 | 내부 배점 |
|---|---:|
| 검색어 일치 비율 | 40점 |
| 주요 보장내용 일치 | 20점 |
| 모든 검색어 일치 | 10점 |
| 관련 보장항목 수 | 15점 |
| 관련 보장 종류 다양성 | 15점 |
| **합계** | **100점** |

- 보장항목 수와 보장 종류 다양성은 각각 전체 DB의 최대값을 기준으로 환산한다.
- 같은 보장 목적·지급조건의 중복 보장명은 한 번 계산하고, 목적이나 지급조건이 다르면 별개로 취급한다.
- 상품명만 일치한 상품은 주요 보장명 일치 상품보다 후순위로 둔다.
- 동점 시 보장내용 일치 개수, 보장 종류 다양성, 보험회사명, 상품명 순으로 정렬한다.
- 계산 점수는 화면에 표시하지 않고 순위와 한 줄 이유만 제공한다.
- 가입조건만 검색한 경우에는 점수나 추천 순위를 부여하지 않는다.

## 5. 필요한 자료

| 자료 | 용도 및 조건 |
|---|---|
| 국내 보험상품 DB | 초기 검증 상품부터 수록, 최종 목표 50개. 추후 버전 확장 |
| 공식 상품안내서·약관·상품요약서 | 보험사 공식 자료를 교차 확인하여 상품정보 검증 |
| 필수 7개 정보 | 보험사, 상품명, 보험 종류, 주요 보장, 공식 출처, 검증일, 당시 판매 상태 |
| 주요 특약·가입조건 | 추천 적격성 및 상세보기용. 미확인 특약은 추천 제외 |
| 보장 분류 연결표 | 큰 분류 → 세부 분류 → 관련 주요 보장명 연결 |
| 검증·제외 목록 | 자료 불일치, 확인 실패 이유, 출처, 확인일, 재검증 필요 사항 |

- 상품 선정 시 보험사와 보험 종류의 다양성을 고려한다.
- 자료가 불일치하거나 판매 상태를 확인하지 못한 상품은 추천에서 제외한다.
- 수집 시와 최종 배포 직전에 판매 상태를 확인한다.
- 원문 PDF 전체는 HTML에 넣지 않고 검증된 구조화 정보만 내장한다.
- 잘못되거나 오래된 상품이 발견되면 그 상품을 제외한 새 HTML 버전을 제작한다. 이전 파일은 임의 삭제하지 않는다.
- 서버 및 외부 연결이 없으므로 HTML 내부 DB가 자동 갱신되지는 않는다.

## 6. 필수 기능과 추가 기능

### 필수 기능

1. 단일 HTML을 서버·로그인·외부 리소스 없이 브라우저에서 실행
2. 단일 및 최대 5개 복수 검색어를 Enter로 등록·삭제하고 검색
3. 검증된 상품 DB에서 조건 불일치 상품을 제외하고 관련 상품 최대 5개 추천
4. 추천 카드, 한 줄 이유, 직접 관련/유사상품 구분 및 자동 비교표
5. PC·모바일 화면 폭 변화에 대응하는 반응형 화면
6. 빈칸·공백·중복어·검색어 초과 입력 처리

### 추가 기능

1. 상품별 상세 팝업(주요 보장·특약·가입조건)
2. 최근 검색어·즐겨찾기(실행 중에만 유지) 및 초기화
3. 조건 검색 전용 전체 목록 및 `더 보기`
4. 브라우저 인쇄·PDF 저장
5. 정식 DB를 50개까지 확대하고 추후 버전으로 확장

## 7. 완료 기준 — 사용자 직접 지정

아래 네 문장을 완료 기준으로 사용한다. 다른 조건을 임의로 추가하여 완료 기준을 변경하지 않는다.

1. **단일 html로 열린다.**
2. **단어를 검색하면 보험 추천 5개가 나온다.**
3. **여러단어를 검색해도 보험추천 5개가 나온다.**
4. **화면을 좁히거나 늘려도 잘리지않는다.**

> 참고: 검증되고 가입조건에 맞는 후보가 5개 미만일 때에는 기존에 확정한 안전 규칙에 따라 그 수만 표시하고 이유를 안내한다. 이는 자료 부족 시의 예외 동작이다.

## 8. 한계 및 비목표 — 3가지

1. **실시간 상품 갱신·가입 연계 없음:** 외부 링크·API·서버 없이 작동하므로 최신 판매 여부나 보험료를 자동 조회하거나 가입을 처리하지 않는다.
2. **개인별 확정 추천 아님:** 건강상태·직업·보험사 인수심사 등을 완전히 확인하지 않으며 가입 가능성, 보장 적합성, 지급 여부를 보증하지 않는다. 보험료도 표시하지 않는다.
3. **가상상품 DB 및 사용자 계정·동기화 없음:** 가상 DB를 제작하지 않고, 로그인·클라우드 동기화·영구 기록 저장도 구현하지 않는다.

## 9. 검증 방법 — 1가지

**실제 검증 상품 DB 기반 시나리오 테스트**를 사용한다.

- 공식 자료를 검증한 실제 상품 50개 확보 후, 예상 상품이 포함되는지 확인하는 정상 검색 10건을 실행한다. 단일·복수·조건·유사상품·중복 제한 사례를 고루 포함한다.
- 빈칸·공백·쉼표·중복어·검색어 6개 입력에 대한 예외 테스트 5건을 실행한다.
- 실패가 있으면 미완료로 기록하고 수정 후 전체 15건을 다시 확인한다. 명확히 불일치하는 가입조건의 상품이나 동일 보험사의 3개 이상 추천 등 기존 필수 제한 위반도 점검한다.
- 입력값·예상 동작·실제 동작·통과 여부를 기록하며, **실행 전에는 테스트 성공으로 표기하지 않는다.**

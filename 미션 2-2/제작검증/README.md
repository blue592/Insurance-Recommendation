- 2026-11-11 기준 공식 상품목록·상품안내에 표시된 이름과 주요 보장 분야를 수록했습니다.

- recommendationEligible=true는 간소화된 공식 상품목록 확인 기준에 대한 표시이며, 개별 가입 승인·실제 판매 확정·보험금 지급 보증을 뜻하지 않습니다.

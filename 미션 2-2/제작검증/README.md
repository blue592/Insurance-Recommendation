# 제작검증

보험추천 미션 2-2의 제작·검증 산출물을 보관합니다.

- [보험상품DB_50개_공식상품확인_v2.js](보험상품DB_50개_공식상품확인_v2.js): 보험사 10곳 × 상품 5개, 총 50개를 공식 보험사 상품목록/상품안내 기준으로 구조화한 새 DB

## 확인 범위 및 주의사항

- 2026-11-11 기준 공식 상품목록·상품안내에 표시된 이름과 주요 보장 분야를 수록했습니다.
- 사용자가 요청한 대로 **약관 검토는 제외**했습니다.
- recommendationEligible=true는 간소화된 공식 상품목록 확인 기준에 대한 표시이며, 개별 가입 승인·실제 판매 확정·보험금 지급 보증을 뜻하지 않습니다.
- 가입 가능 연령이 확실하지 않은 항목은 null로 두고, 상품 유형과 심사에 따라 달라질 수 있다고 표시합니다.
- 기존 미션 2-2/보험상품DB_50개.js는 보존했습니다. HTML에는 아직 자동 통합하지 않았습니다.

## 2. 기획서 핵심
- 서버·로그인·외부 연결 없는 단일 HTML, 검색어 최대 5개, 추천 최대 5개(같은 보험사 최대 2개)
- 공식 자료로 검증한 실제 상품만 수록 (가상 DB 금지, 최종 목표 50개)
- 완료 기준: ① 단일 html로 열림 ② 단어 검색 시 추천 5개 ③ 여러 단어 검색 시 추천 5개 ④ 화면 폭 변화에도 잘리지 않음

2. 웹 검색으로 상품 자료 확인 → 공식 상품안내서가 확인된 ABL생명 2개 상품만 수록
   - (무)우리WON건강N더보장종합보험(해약환급금 미지급형)2601
   - (무)우리WON케어간병보험(해약환급금 미지급형)2607

3. 보험추천v1.html 제작 및 스크립트 문법 검사(통과)

## 4. 구현 기능
- 검색어 칩 등록·삭제(Enter), 중복·빈칸·쉼표·5개 초과 처리
- 추천 점수 계산·동점 정렬, 직접 관련/유사상품 배지, 한 줄 추천 이유
- 가입조건(나이·성별) 필터, 조건 전용 목록과 `더 보기`
- 비교표(모바일 세로 카드 전환), 상세 팝업, 최근 검색어, 즐겨찾기, 기록 초기화, 인쇄·PDF
- 수정 후 재검색 전 기존 결과에 `이전 검색 결과` 표시

### 수정 기록 1 — 모바일 검색 버튼 및 결과 이미지 저장 개선

- **수정 버전:** `미션 2-3/보험추천_챗지피티v2.html`

**발견한 문제**

모바일에서 Enter를 이용해 검색어를 등록하기 어려워 검색을 진행하지 못하는 문제가 있었다. PDF 저장하기 버튼이 눌리지 않는 등 모바일에서 버튼이 비활성화되는 문제도 있었다.

**AI에게 전달한 요청**

> 모바일에서는 버튼들이 다 안눌리고 비활성화되어있어
> 검색 단어추가가 안되고 검색어가 등록되지 않는 문제를
> 인쇄/pdf저장 버튼도 눌리지않아. 모바일은 그냥 버튼 클릭으로하자
> 원본은 두고 새로운 보험추천_챗지피티v2.html 로 만들거야. 아직은 만들지 말고 모바일 버튼 활성화 할수있는 방법 제안해줘

**수정 후 테스트 결과**

사용자가 제공한 모바일 캡처를 정리한 기록에서 **‘암·뇌·심장’이 검색어로 등록된 상태와 보험상품 5개가 표시된 결과**를 확인했다. 검색 결과 이미지 1장이 생성되어 표시되었으며, 해당 이미지에는 검색어·상품 5개·보장 내용·안내 문구가 잘리지 않고 포함되어 있었다.

**사용자는 모바일 화면에서 검색 버튼과 이미지 저장 버튼이 활성화되어 터치할 수 있음을 확인했다.**

**수정 이유**

검색어를 등록하지 못하면 모바일 사용자는 추천 결과를 확인하는 단계까지 진행할 수 없다. 단어 추가와 검색을 버튼으로 구분하여 다음에 해야 할 행동을 쉽게 알 수 있도록 개선했다. 또한 결과 저장이 되지 않으면 같은 내용을 다시 검색하거나 여러 화면을 따로 캡처해야 하므로, 결과를 이미지로 확인하고 보관할 수 있는 방법을 마련했다.

### 수정 기록 2 — 검색 결과가 없는 단어의 매칭과 안내 개선

- **수정 버전:** `미션 2-3/보험추천_챗지피티v3.html`

**발견한 문제**

기존 PC 비교 테스트에서 **‘화상’, ‘화상+감기’를 검색했을 때 추천 결과가 0개**로 표시되었다. 결과가 없다는 안내만으로는 사용자가 어떤 단어로 다시 검색해야 하는지 알기 어려웠다.

기존 코드 점검 기록에서는 내장 DB의 상세 보장 정보와 검색 표현이 부족하고, `+`를 여러 검색어의 구분자로 처리하지 않는 문제가 확인되었다. 따라서 결과 없음 안내와 함께 검색어 처리·매칭 범위를 보완할 필요가 있었다.

**AI에게 전달한 요청**

> PC 비교 테스트에서 '화상', '화상+감기' 검색 시 추천 결과가 0개로 표시되었어. 결과가 없다는 안내는 확인되었지만, 사용자가 다른 검색어를 선택하도록 돕는 구체적인 안내는 개선이 필요할거같아. 오류를 찾아줄수있어? 기존의 원본은 만지지말고 미션2-3 에 보험추천_챗지피티v3.html 새로만들어야해 .아직은 만들지말고 제안을해줘.

**수정 후 테스트 결과**

**‘화상’ 검색 시 관련 분야 보험 1개가 표시된 것**을 v3의 사용자 PC 캡처에서 확인했다.

**v4에서 추가로 ‘화상+감기’를 함께 검색했을 때도 결과가 나왔으며, 화면에 ‘관심 보장과 관련된 보험 5개’라는 제목과 첫 페이지의 상품 카드 3개가 표시된 것을 확인했다.** PC Chrome의 인쇄 미리보기와 PDF 저장 설정 화면도 표시되었다.

추가 복수 검색 테스트는 **v4 파일에서 ‘공식 보장·기능 확인 상품만 검색’ 옵션을 해제하고 원본 자료를 포함한 59개를 검색한 조건**이다. 따라서 v3의 단일 검색과 실행 파일·검색 조건을 구분해 기록했다. 해당 캡처에서 4·5번 카드의 전체 내용과 PDF 파일의 실제 저장 완료까지 확인한 것은 아니다. 결과에는 ‘관련 분야 · 보장 미확인’ 안내가 표시되어 있다.

**수정 이유**

결과가 없다는 문구만 표시되면 사용자는 검색어가 잘못된 것인지, 자료가 부족한 것인지 판단하기 어렵고 다른 단어를 반복해서 추측해야 한다. 검색 표현과 관련 분야 안내를 보완하여 탐색을 이어갈 수 있도록 했다. 또한 관련 분야의 상품을 해당 질병이나 상해의 보장이 확인된 상품으로 오해하지 않도록, 직접 일치 여부와 미확인 사항을 구분해 표시했다.

### 수정 기록 3 — 검색창 안내와 분류별 단어 예시 추가

- **수정 버전:** `미션 2-3/보험추천_챗지피티v4.html`

**발견한 문제**

검색창에 표시되는 단어 예시가 충분하지 않아, 보험에 익숙하지 않은 사용자는 어떤 단어를 입력해야 원하는 상품을 찾을 수 있는지 알기 어려웠다. 검색 기능이 있어도 사용자가 질병명이나 보장 이름을 직접 떠올려 입력해야 하는 불편이 있었다.

**AI에게 전달한 요청**

> 검색창에 표시되는 단어 예시가 충분하지 않아 보험에 익숙하지 않은 사용자는 어떤 단어를 입력해야 원하는 보험상품을 찾을 수 있는지 알기 어렵고 , 검색 기능이 있더라도 입력할 단어를 떠올려야 하는 불편이 있어 . 어떻게 하면 이문제를 해결할수있을까?

**수정 후 테스트 결과**

사용자는 **성별 선택(여자·남자) → 중간 분류 선택(건강·질병 등) → 세부 단어 예시 선택(암·뇌·심장 등)** 순서로 검색 단어 예시를 클릭할 수 있음을 확인했다. **실손은 건강 분류의 세부 단어**로 제공된다.

기존 PC 캡처에서도 검색창 안내와 건강·질병 분류별 단어 예시가 표시된 것을 확인했다. 예시 클릭 가능 여부는 이번 사용자의 직접 확인 내용을 반영했다.

**수정 이유**

검색어 예시가 부족하면 사용자는 무엇을 입력해야 할지 몰라 검색을 시작하기 어렵다. 분류별 예시를 제공하여 관심 있는 항목을 보고 선택할 수 있도록 하고, 단어를 직접 반복해서 입력하는 부담을 줄이려 했다. 기존 검색어 칸에 선택한 단어가 모이도록 구성하여 여러 관심 항목을 함께 검색하는 흐름도 이해하기 쉽게 개선했다.

## 사용자 테스트

### 성별 단독 선택 및 다른 검색어 조합 시 검색 결과 없음

- **테스트 참여자:** 30대 여성 친구 
- **테스트 일자:** 2026-11-12
- **테스트한 작업과 행동:** 편하게 단어를 검색해보라고 하였다.  ‘여성’ 또는 ‘남성’을 단독으로 선택하여 검색하고, 성별과 다른 단어를 조합하여 검색함. 그외 여러 단어를 검색
- **실제 결과:** 성별 단독 선택 시에도 검색 결과가 나오지 않았고, 성별과 다른 단어를 조합했을 때도 검색 결과가 0개로 표시됨.
- **받은 피드백:** “성별 + 다른 단어 조합시 검색결과 0인 오류”, “성별선택시에도 검색결과가안뜸”.
- **사용자가 겪는 불편:** 화면에 제시된 성별을 선택해도 추천을 확인할 수 없으며, 성별과 관심 보장을 함께 지정해 상품을 찾기 어려움.
- **반영 내용과 결과:** 저장소 v5에는 성별 동의어, 성별 미상 상품의 탐색 허용, 관련 상품 우선 정렬 및 ‘성별 없음’ 버튼이 반영되어 있다.  여자/여성과 남자/남성의 결과가 각각 같고, 성별 단독 및 성별+암 검색 결과가 나오는 것을 검색 실행으로 확인했다.
- **후속 근거:** [최종본 검증 상세](제작검증/보험상품DB_60개추가_최종본검증.md).

## 최종본 수정·검증 기록 — 보험상품 DB 추가 60개

- **대상:** [보험추천_챗지피티v6_.html](보험추천_챗지피티v6_.html)
- **기록일:** 2026-11-12

### 발견한 문제

기존 DB 59개만으로는 사용자가 요청한 여러 보험사와 농작물·사업자·디지털·골프·장기체류 등 상품 분야를 충분히 탐색하기 어려웠다. 실제 판매 여부와 보장 근거를 구분하지 않으면 미확인 상품을 확인된 상품으로 오해할 수 있었다.

### AI에게 전달한 요청

기존 DB와 중복되지 않는 실제 상품을 회사별·카테고리별로 분석하고 10개씩 추가하도록 요청했다. 처음에는 5개 회사의 50개였으나 한화손해보험을 추가하여 6개 회사의 60개가 되었다. 이후 첨부 HTML을 최종본으로 커밋하고 대화내용·제작검증기록을 반영하며 분석 문서와 JSON을 제작검증 폴더에 넣도록 요청했다.

### 반영 내용

- 6개 회사 각 10개를 추가하고 기존 59개 레코드를 보존했다.
- 추가 60개의 보장·분류·출처·확인 상태를 분석 문서와 JSON으로 함께 기록했다.
- 기본 검색은 기존 확인 11개 + 추가 확인 31개 = 42개이며, 필터를 해제하면 119개를 탐색한다.
- 최종본 파일명은 사용자가 첨부한 이름 그대로 유지했다. 내부 제목 v7과의 차이는 검증기록에 명시했다.

### 수정 이유

보험사와 상품 분야를 늘려 사용자가 원하는 상품을 찾을 가능성을 높였다. 동시에 확인 수준과 출처를 남겨, 검색 결과가 있다는 이유만으로 현재 판매·가입 가능·직접 보장이 확정된 것으로 이해하지 않도록 했다. 최종본과 이전 v5의 기능 차이를 기록하여 누락된 개선을 추적할 수 있게 했다.

### 추가 연결 — 사용자 PC의 DB 업데이트 결과

커밋 준비 중 추가된 [DB업데이트.md](제작검증/DB업데이트.md)와 사용자 캡처 2장을 보존하고 연결한다. 해당 문서에는 v7 추가 60개 실행 화면에서 전체 119개·확인 상품 42개 안내, 여자 단독 42개 및 남자+운전자 3개 결과가 표시되었다고 기록되어 있다. 이는 기존 문서에 기록된 사용자 PC 결과이며 이번 작업에서 캡처를 새로 판독하거나 실제 검색을 재현한 결과는 아니다. 파일명은 이번 첨부본과 다르므로 실행 파일의 바이트 동일성까지 캡처로 확정하지 않는다.

모바일·인쇄·이미지 저장 완료와 전체 DB 매칭 정확성은 여전히 미확인이다. 초기 오류 기록의 남자 단독·여자+운전자 조합과 사용자 캡처의 조합도 다르므로, 캡처만으로 모든 초기 오류가 해결되었다고 판정하지 않는다.

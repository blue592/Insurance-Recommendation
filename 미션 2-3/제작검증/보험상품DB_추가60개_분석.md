# 보험상품 DB 추가 60개 분석

조사일: 2026-11-12 · 기존 59개 + 추가 60개 = 통합 119개

현대해상·NH농협손해보험·롯데손해보험·흥국화재·흥국생명·한화손해보험 각 10개입니다. 이번 수정에서는 한화손해보험 10개만 추가했고 앞서 등록한 109개 레코드는 그대로 보존했습니다.

**현재 판매 확정 60개라는 의미는 아닙니다.** 공식 상품안내 확인 31개(품목별 모집기간이 있는 농작물보험 1개 포함), 공식 판매목록 확인·상세 재확인 13개, 원문 접근 문제로 현재 판매 재확인 16개를 구분했습니다. 한화손해보험은 6개를 공식 상품몰 상세페이지에서 확인했고, 골프·자동차·연금저축·실손 4개는 공식 검색자료를 확인했으나 원문 제한·시간초과로 재확인 대상으로 두었습니다.

가입 승낙·개별 보험료·보험금 지급을 검증한 자료가 아닙니다. 보장 요약에는 선택특약이 포함되며 약관 전체를 대조하지 않았습니다. 최신 판·자기부담금·면책·감액·갱신 조건을 미확인 상태에서 임의로 확정하지 않았습니다.

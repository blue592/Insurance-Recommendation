상품정보와 검색 기준

원본 50개 + 공식 상품안내 확인 9개 = 59개를 보관합니다. 기본 검색은 추가 9개와 원본 중 보강한 2개, 총 11개만 사용합니다. 약관 대조는 검증 범위에서 제외했습니다. 원본 자료 48개는 삭제하지 않고 별도 선택으로 검색할 수 있습니다.

  • 확인 완료 기준: 보험사 공식 상품안내에 상품명과 수록할 보장·기능이 있고 출처를 기록한 경우입니다. 가입 승인·현재 청약 가능 여부·보험금 지급 검증을 뜻하지 않습니다.
  • 검색 표현 500개에는 동의어·생활 표현·접미 표현이 포함됩니다. 500개 보장을 뜻하지 않으며 외부 형태소 분석기는 사용하지 않습니다.
  • 자료 문구 일치를 우선하며 관련 분야는 직접 보장 미확인으로 표시합니다. 복수 검색어 중 일부만 일치할 수 있으며 직접 미일치 단어를 안내합니다.
  • 가입대상 필터·최대 5개 검색어·보험사당 최대 2개 추천·상세보기·즐겨찾기·최근검색·초기화·인쇄·이미지 저장을 유지합니다.
  • 건강검진 자체와 치료는 다릅니다. 요양병원·요양원·장기요양등급, 간병인 사용·간호간병통합서비스는 서로 다릅니다. 유니버설은 확인 상품이 없어 결과를 임의로 채우지 않습니다.
  • 실제 화면·기기별 인쇄·이미지 저장은 브라우저에 따라 다를 수 있습니다. 검증기록은 코드 검사와 실제 브라우저 검사를 구분합니다.
  • 외부 통신·자동 갱신 없음. 기록·즐겨찾기는 새로고침 시 초기화됩니다.

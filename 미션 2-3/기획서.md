# 보험추천 최종기획서

> **최종 버전:** `보험추천_챗지피티v6_.html`  
> **제출 위치:** `미션 2-3/기획서.md`

## 1. 대상 사용자

- 나와 보험추천 받고싶은 친구

## 2. 사용 목적

관심 있는 단어 하나 또는 여러 개를 입력하면, 보험상품 중 관련성이 높은 상품을 최대 5개 보여준다.

## 3. 화면 구성과 동작

### 3.1 첫 화면

- 중앙에 검색 입력창과 사용 안내를 배치한다.
- 파스텔톤, 둥근 카드·버튼, 간결한 아이콘을 사용한다.
- 최근 검색어는 첫 화면에, 즐겨찾기는 별도 메뉴에 표시한다.
- **(추가)** 입력창 옆에 `＋ 단어 추가`와 `검색하기` 버튼을 배치한다.
- **(추가)** 검색창 아래에 성별 선택과 분류별 검색어 예시를 제공한다.

| 구분 | (추가) 화면에 제공하는 항목 |
| --- | --- |
| 성별 | 여자, 남자 |
| 큰 분류 | 건강, 질병, 상해, 운전자, 어린이, 여행, 기타 |
| 세부 단어 예시 | 실손, 간병, 암, 뇌, 심장, 감기, 화상, 골절, 수술, 입원 등 |
| 검색 표현 안내 | `검색 표현 500개 보기` 펼침 영역 |
| 검색 범위 | `상품안내 확인 상품만 검색 (42개)` 선택란 |

- **(추가)** 큰 분류 버튼은 세부 예시 목록을 바꾸는 역할을 한다. 세부 단어를 눌렀을 때 검색어로 등록된다.
- **(추가)** 성별은 선택 사항이며, 선택하지 않아도 검색할 수 있다.

### 3.2 검색어 등록

1. **(추가)** 단어를 입력한 뒤 `＋ 단어 추가` 버튼 또는 Enter로 등록한다. 모바일에서는 버튼을 이용할 수 있다.
2. 검색어는 최대 5개까지 등록하며, 칩의 `×`로 삭제한다.
3. **(추가)** `+`, 쉼표 등으로 구분한 여러 단어를 등록할 수 있다. 예: `화상+감기`.
4. 중복 단어는 한 번만 등록하고 안내한다.
5. 빈칸·공백만 입력하면 “검색어를 입력해 주세요.”라고 안내한다.
6. **(추가)** 검색어 하나는 30자 이내이며, 5개를 초과하면 수정 안내를 표시한다.
7. **(추가)** 입력창에 단어가 남아 있는 상태에서 `검색하기`를 누르면 해당 단어를 등록한 뒤 검색한다.
8. 검색어 변경 후 다시 검색하기 전에는 기존 결과를 `이전 검색 결과`로 표시한다.

### 3.3 검색·추천 결과

- **(추가)** 상품명, 주요 보장, 보험회사, 보험 종류, 등록된 검색 키워드와 보장 근거 문구를 검색한다.
- **(추가)** 등록된 동의어와 부분 일치를 활용한다. 모든 오타나 임의의 표현을 자동으로 이해하는 기능은 아니다.
- 관심 보장 검색은 관련 상품을 최대 5개 표시한다. 같은 보험사는 최대 2개까지 선정한다.
- **(추가)** 여러 관심 단어 중 일부만 일치해도 후보가 될 수 있으며, 더 많은 단어가 일치하는 상품을 우선한다.
- **(추가)** 카드에는 다음 구분을 표시한다.
  - `자료 문구 일치`
  - `관련 분야 · 보장 미확인`
  - `조건 일치` 또는 `성별 추가필터 적용`
- 결과가 5개보다 적으면 찾은 개수만 표시하고 검색어 수정 안내를 제공한다.
- **(추가)** 직접 일치하는 문구가 없는 검색어는 별도로 안내한다. 관련 분야 결과를 해당 보장이 확인된 결과로 표현하지 않는다.

### 3.4 성별 및 가입대상 검색

- **(추가)** `여자·여성`, `남자·남성`을 각각 같은 성별 조건으로 처리한다.
- **(추가)** 성별 조건에서는 가입대상 설명으로 확인되는 반대 성별 전용 상품을 제외한다.
- **(추가)** 성별 정보가 없는 상품도 후보에 포함하고 `성별 조건 확인 필요`를 표시한다.
- 어린이, 운전자, 유병자 등 등록된 가입대상 조건은 상품의 조건 정보와 대조한다.
- **(추가)** 연령 검색은 코드에서 확인 가능한 연령 정보에 한정한다. 모든 상품의 가입연령을 판정하지는 못한다.
- 조건만 검색하면 순위 없이 보험회사명·상품명 가나다순으로 표시하고, 처음 5개 이후 `더 보기`로 추가 표시한다.
- 관심 보장을 함께 검색하면 최대 5개 추천 방식으로 전환한다.

### 3.5 비교·상세보기·기록

- 추천 카드 아래 비교표에 보험회사, 상품명, 보험 종류, 주요 보장을 표시한다.
- 모바일에서는 비교표를 상품별 세로 형태로 표시한다.
- **(추가)** 상세보기에는 가입조건, 확인된 연령 정보, 자료 확인일, 판매 상태 기록, 출처 주소, 미확인 사항을 표시한다.
- **(추가)** 출처 주소는 텍스트로 보관하며 외부 페이지로 자동 연결하지 않는다.
- 검색기록과 즐겨찾기는 현재 HTML 실행 중에만 유지하며, 새로 열거나 새로고침하면 초기화된다.
- 사용 중 기록 초기화 기능을 제공한다.
- **(추가)** 별도의 펼침 영역에서 새로 추가한 60개 상품과 확인 상태를 볼 수 있다.

### 3.6 결과 출력·저장 (추가)

- `인쇄` 버튼으로 브라우저 인쇄창을 호출한다. PDF 저장은 브라우저가 제공하는 기능을 이용한다.
- `이미지 저장` 버튼으로 현재 표시된 검색 결과를 PNG 이미지로 생성한다.
- 내용이 길면 여러 장으로 나누며, 이미지 미리보기와 다운로드 링크를 제공한다.
- 모바일에서는 생성된 이미지를 길게 눌러 저장하는 방법도 안내한다.
- 버튼 구현 여부와 실제 기기의 저장 완료 여부는 구분하여 검증한다.

## 4. 추천 규칙

**(추가)** 원본 기획서의 100점 배점표를 최종 HTML에 구현된 다음 규칙으로 변경한다.

| 순서 | 최종 적용 규칙 |
| --- | --- |
| 1 | 선택한 검색 범위와 가입대상 조건에 맞는 후보를 추린다. |
| 2 | 관심 검색어가 검색 대상 문구에 직접 일치하는지 확인한다. |
| 3 | 직접 일치하지 않는 단어는 등록된 관련 분야 연결표로 확인한다. |
| 4 | 직접 일치한 검색어가 많은 상품을 우선한다. |
| 5 | 직접 일치 개수가 같으면 관련 분야 일치 개수를 반영한다. |
| 6 | 동점이면 보험회사명·상품명 가나다순으로 정렬한다. |
| 7 | 추천 검색에서 같은 보험사 최대 2개, 전체 최대 5개를 선정한다. |

- **(추가)** 내부 점수는 `직접 일치 검색어 수 × 100 + 관련 분야 일치 검색어 수`로 계산한다.
- 계산 점수는 화면에 표시하지 않고 순위와 추천 이유를 제공한다.
- **(추가)** 가입조건만 검색하는 전체 목록에는 추천 순위와 보험사별 2개 제한을 적용하지 않는다.
- **(추가)** 결과 수를 채우기 위해 관련 없는 상품을 추가하지 않는다.

## 6. 필수 기능과 추가 기능

### 6.1 필수 기능

1. 단일 HTML을 서버·로그인·외부 리소스 없이 실행한다.
2. **(추가)** 버튼 또는 Enter로 검색어를 최대 5개 등록·삭제한다.
3. 단일·복수 검색어로 관련 상품을 최대 5개 추천한다.
4. 추천 카드, 추천 이유, 결과 구분, 비교표를 제공한다.
5. PC·모바일 화면 폭에 대응한다.
6. 빈칸·공백·중복어·검색어 초과 입력을 처리한다.
7. **(추가)** 분류별 단어 예시와 검색 결과 부족 안내를 제공한다.
8. **(추가)** 성별 동의어를 처리하고 성별 미확인 상품도 탐색 후보에 포함한다.

## 7. 완료 기준

기존에 사용자가 지정한 네 가지 완료 기준을 유지한다.

1. **단일 html로 열린다.**
2. **단어를 검색하면 보험 추천 0개~5개가 나온다.**
3. **여러단어를 검색해도 보험추천 0개~5개가 나온다.**
4. **화면을 좁히거나 늘려도 잘리지않는다.**

## 8. 한계 및 비목표 — 3가지

1. **실시간 상품 갱신·가입 연계 없음**  
   외부 API나 서버로 최신 판매 여부·보험료를 자동 조회하지 않으며, 보험 가입이나 결제를 처리하지 않는다.
2. **개인별 가입·지급 확정 없음**  
   건강상태·직업·인수심사·약관 전체를 분석하여 가입 가능성이나 보험금 지급을 확정하지 않는다. 보험료도 산출하지 않는다.
3. **계정·동기화·영구 기록 저장 없음**  
   로그인과 클라우드 동기화를 제공하지 않는다. 검색기록과 즐겨찾기는 실행 중에만 유지하며, 출력한 이미지·PDF는 사용자가 별도로 보관한다.

**(추가)** 위 비목표는 최종 HTML의 내장 DB 검색 방식과 실행 중 기록 유지 방식에 맞춰 정리했다.
